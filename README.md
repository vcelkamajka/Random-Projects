This project folder contains various random projects which are not typically connected.

The 'Arm Slider' project uses matplotlib sliders to animate an arm which has a connected forearm. The sliders control both the arms and forearms angles seperately. Length can be varied as a constant for both.

The 'Equal Area' project finds all the squares of a value, creating a nice visual of each x, y component of a value.

The 'Intercept Finder' finds all intercepts for two objects moving linearly at different angles and velocities.

The 'Pixelator' pixelises a given image into a set resolution.

The 'Rock Paper Scissors' project runs a simulation on rock paper scissors games, including one where choices are weighted.
